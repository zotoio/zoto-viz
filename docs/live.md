# Live monitor

`python -m service.monitor` captures with `tshark`, discovers names, and serves `web/dist` plus `/ws` at 1 Hz.

Header: connection, brand, interface LEDs, rates, device counts.

Controls: **view** (type to filter; grouped graph / demo / arcade), view cog (Settings → This view), **dream**, **feed**, **debug** (side panel: monitor log + Cursor tokens/cost), **labels**, **cam**, **mic**, **dice**, **AI**, settings cog. Feed stays up in mosaic and arcade; drag any empty chrome on **feed** / **debug** / **settings** to move them (not the text or controls), and the corner grip to resize (remembered). Mosaic tiles have corner **look** / **max** / **close**; drag a tile onto another to swap views, and drag gutters to resize. Settings → Mosaic **one theme** uses the header palette on every tile. About half of dice / new-wall rolls give every pane a sky no other pane has (`anim.mosaicUniqueSkies`); plugin shaders stay unique per zip. Per-view options, plugin config, and arcade knobs live on **This view** — the cog next to the view menu opens that tab. **Dice** is a header on/off switch: on rolls now, then every **N minutes** (Settings → Dice **every**). Off stops the cadence. **Roll now** on that pane (and MCP `roll_dice`) is always one shot. A roll randomizes the groups left on (theme, catalog view, mosaic, feed, motion, physics, and every view’s knobs by default; chrome, camera, and microphone stay), then optionally turns on **AI** cycling + Control. Views that still need a key or OAuth (Nest cams until Device Access is linked, Guardian rain until `api-key=test` is replaced) stay out of the roll. Setup links live on Settings → Sources / Agent and on the view itself. A roll does not start a chat or think turn. Dice stays under operator-set soft ceilings on labels, traffic sparks, mosaic tiles, feed density, and view node-count knobs so a roll does not tank the frame — Settings sliders still go to the full range. Privacy filters and prompts stay as they were. **AI** is a toggle: on (when the model is reachable) writes a profile named after the Ollama model (autosaved) with **AI Dynamic** sky, dream camera, view cycling, randomized motion, and cadence theme changes, and turns on **AI Control**. Off restores the previous profile. Selecting that agent profile while the model is offline loads the saved look only — it does not create a new profile or start cycling. The chip’s LED is dim when idle, pulses amber while the local model is thinking, and the overlay shows a `thinking…` line until the first token.

Settings is one drawer with a left nav: Appearance, This view (plugin options / config / arcade knobs / per-view AI prompt), Graph (Network / System / Look), Physics (traffic sparks, magnets, gravity, strings), Motion, Dice (repeat switch + minutes cadence, which groups a roll includes, cycling, and dice-only ceilings), Camera, Audio, Feed, Sources (RSS / HTTPS / local files / user journal / kernel ring), Privacy (webcam / microphone, redact, plus host / subnet filters), Agent. **Nest cams** (`plugin:nest-cams`) is Device Access live cameras — see [SDM](/sdm). SYS views (memory, disk, GPU, sockets, cgroups, user units, udev) are catalog rows like CPU cores; they read `views.*` from the 1 Hz snapshot, not the packet LAN. **SYS Syscon** opens those eight as a 2×4 mosaic wall. **NET Cypher CIC** opens a neon center-hero wall: holodeck infograph in the middle, system and network graphs on the sides.

Feed **source**: traffic (decoded packets), **transcript** (agent conversation plus chain of thought, with a type / mic / send bar), or **both**. Every source appends at the bottom so older lines scroll up — the overlay does not replace the visible list. Live agent think/reply rows stream on traffic too. Saying the watchword opens the transcript overlay, pins it to the latest line, and marks **listening** until you say **send**. **zoto stop** cuts spoken replies until the watchword is said again. Settings → Feed **text** (10–20 px) sizes the ticker; the ticker follows the latest line as it streams. Header **feed** / `F` still shows or hides the overlay; on a view narrower than four feed-widths the graph eases left by half the overlay (right when chrome is on the right).

Profiles: `~/.zoto-viz/profiles.yml`. Shipped id `zoto-viz` (label **zoto viz**) is read-only. A leftover `netviz` id is migrated on read. Writable profiles **always autosave**. The shipped factory look cannot be overwritten: the first edit writes onto the working profile (`user`, or the current startup default). If the monitor is down when the page loads, the bar says so and retries on WebSocket reconnect (and on a short backoff) — a blip does not leave the file marked unavailable. Header **AI** creates a writable profile whose id and label are the Ollama model tag (for example `gemma4:latest` → id `gemma4-latest`). A legacy id `ai` is migrated on the next online activate. A reload in the same tab restores the live look from session storage (theme, view, mosaic, motion, feed, selection, cam / mic) instead of jumping back to the startup default. Closing the tab drops that snapshot.

Keyboard: `1–9`/`0` views, `D` dream, `F` feed, `B` debug logs, `L` labels, `R` redact, `T` theme.
