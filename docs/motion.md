# Views and motion

Shipped views live in `web/src/core/modes.ts`: Topology, Top talkers, Services, Protocols, Layers, Watch, arcade games, and CPU views.

**Dream** (header or `D`) orbits the graph toward activity. Motion settings: sky, floor, pulse, edge glow, mosaic tiles.

Sky **cycle** walks far-field skies. The webcam is **not** started just because cycle is on — only when the sky is actually `live`, or gaze / live colour is on. See [Camera](/camera).
