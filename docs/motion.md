# Views and motion

Shipped views live in `web/src/core/modes.ts`: Topology, Top talkers, Services, Protocols, Layers, Watch, arcade games, and CPU views.

**Dream** (header or `D`) orbits the graph toward activity. Motion settings: sky, floor, edge glow, mosaic tiles. Mosaic is a split wall: drag a tile caption to swap, drag the gutters to resize (saved), and use the corner **look** / **max** / **close** chips — close expands the neighbour so no gap remains. Orbit / pan / zoom still work inside every tile. **Look** applies that tile's sky and colour. Settings → Mosaic **one theme** paints every tile with the header palette; off keeps a different palette per view. Settings → Mosaic assigns views per tile and can reset or equalize the splits. Dice **mosaic** off leaves the grid alone; Settings → Agent → **AI mosaic layout** off lets the model change tile views (`anim.mosaicTiles`) but not the splits. Settings → Graph → Look **layout** pins a host placement on any graph view (`auto` keeps the plugin's own force; `tree` / `radial` / `rings` / `cluster` / `layers` / `globe` / `bars` / `scatter` / `force` come from the usual 3D graph libraries; animated models sit beside them; **sierp** / **hilbert** / **koch** / **julia** are fractal, **fft** / **fall** / **carrier** / **array** are radio/FFT, **heap** / **trie** / **hash** / **matrix** / **queue** are data-structure insights — rate, hops, IPv4 prefixes, hash collisions, last-seen). Mic FFT bins drive spectrum/waterfall/array when the pulse microphone is on; otherwise those layouts DFT live node rates. **links** adds directional arrows and hub-bundled curves. Camera **focus** can frame the selected node and its neighbours. **Physics** (Settings) cuts traffic sparks (density, rate, quiet, peak, cap, size, speed), magnets each node type to attract or repel, sags edges into strings, and adds gravity / swirl / spread / springs. Pulse those from Audio → modulate (**physics**, **sparks**). Audioreactivity (drive, sensitivity, what the pulse moves) lives under Settings → **Audio**; header **mic** gates the pulse microphone. Header **dice** rolls the groups left on in **Settings → Dice** (theme, catalog view, mosaic, feed, motion, physics, and every view’s knobs by default; chrome placement stays), then optionally hands cycling back to the local agent. Rolls stay under operator-set soft ceilings on labels, sparks, mosaic tiles, feed density, and node-count knobs; sliders still reach the full range. MCP, profile load, and plugin looks also pass a readability floor so stacked camera / physics / spark / label drives cannot twitch the orbit or bury names. Left-drag orbits; two-finger drag / mouse wheel zooms (up in, down out); Ctrl + two-finger or right-drag pans. Settings → Motion → floor **follow** blends a world-fixed grid (0%) with a floor that sits under the graph (100%) so those moves keep tiles and nodes together. Height, scale, and fade hold through small focus jitter so the tiles do not flash. The pose stays where you release; double-click refits. **Layers** internet destinations undulate, shimmer, and cycle cube / star / octahedron faces on a slow cadence. The local agent (AI Control) can author a **custom GLSL sky**, pin photos or SVG on the graph, and write any Motion / Camera / Graph / Physics setting; that look is stored on the profile named after the Ollama model.

Sky **cycle** walks authored far-field skies (fractal, space, matrix, aurora, rain, ocean, fire, warp, clouds, circuit, plasma, lattice, dusk, void, VHS, nebula, acid, ice, dawn, phosphor, photographic Earth / meadow / tunnel / bomb / reef / tornado / desert / amazon / aquarium / macaws / ruins / fungi, and live). Settings → Motion groups them (nature / photo / digital / live / plain) and filters by name. Photo skies prefer a muted looping `/skies/<id>.webm` (or `.mp4`), then the JPEG poster. A video plate plays 1:1 with no Ken Burns; the host dual-decodes and crossfades the last 0.35 s onto t=0 so the wrap is seamless. A JPEG eases a closed 5 s Ken Burns until a clip lands. They do **not** open the webcam. The webcam is **not** started just because cycle is on — only when the sky is actually `live`, or gaze / live colour is on. See [Camera](/camera). Host RSS / HTTPS / file feeds live under Settings → **Sources**; see [Sources](/sources).

**AI Dynamic** is a separate sky: Gemma invents a colour/motif recipe (`POST /api/ai/sky`) and the shader paints it, easing the palette between recipes. How often it rebuilds is the **weather** strip on Settings → Agent (probability bands: hush / drift / pulse / storm). Default **drift** rolls about once a minute. Click **AI Dynamic** again to rebuild now. Cycle / randomize never pick Dynamic. Each view has a **prompt** on Settings → This view (stored on the active profile) that prefixes the sky request for that view. Editing that prompt rebuilds the Dynamic sky once typing pauses. Agent **temper** prefixes the chat system prompt and scales Ollama temperature. AI Control theme and physics jumps ease chrome, fog, node colours, magnets, gravity, swirl, and strings over a couple of seconds.
