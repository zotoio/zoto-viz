# Views and motion

Shipped views live in `web/src/core/modes.ts`: Topology, Top talkers, Services, Protocols, Layers, Watch, arcade games, and CPU views.

**Dream** (header or `D`) orbits the graph toward activity. Motion settings: sky, floor, edge glow, mosaic tiles. **Physics** (Settings) cuts traffic sparks (density, rate, quiet, peak, cap, size, speed), magnets each node type to attract or repel, sags edges into strings, and adds gravity / swirl / spread / springs. Pulse those from Audio → modulate (**physics**, **sparks**). Audioreactivity (drive, sensitivity, what the pulse moves) lives under Settings → **Audio**; header **mic** gates the pulse microphone. Header **dice** rolls the groups left on in **Settings → Dice** (theme, catalog view, mosaic, chrome, feed, motion, physics, and every view’s knobs by default), then optionally hands cycling back to the local agent. Rolls stay under operator-set soft ceilings on labels, sparks, mosaic tiles, feed density, and node-count knobs; sliders still reach the full range. Two-finger / wheel zoom and perspective pan stay where you release; double-click refits. **Layers** internet destinations undulate, shimmer, and cycle cube / star / octahedron faces on a slow cadence. The local agent (AI Control) can author a **custom GLSL sky**, pin photos or SVG on the graph, and write any Motion / Camera / Graph / Physics setting; that look is stored on the profile named after the Ollama model.

Sky **cycle** walks authored far-field skies (fractal, space, matrix, aurora, rain, ocean, fire, warp, clouds, circuit, plasma, lattice, and live). The webcam is **not** started just because cycle is on — only when the sky is actually `live`, or gaze / live colour is on. See [Camera](/camera).

**AI Dynamic** is a separate sky: Gemma invents a colour/motif recipe (`POST /api/ai/sky`) and the shader paints it, easing the palette between recipes. How often it rebuilds is the **weather** strip on Settings → Agent (probability bands: hush / drift / pulse / storm). Default **drift** rolls about once a minute. Click **AI Dynamic** again to rebuild now. Cycle / randomize never pick Dynamic. Each view has a **prompt** on Settings → This view (stored on the active profile) that prefixes the sky request for that view. Editing that prompt rebuilds the Dynamic sky once typing pauses. Agent **temper** prefixes the chat system prompt and scales Ollama temperature. AI Control theme and physics jumps ease chrome, fog, node colours, magnets, gravity, swirl, and strings over a couple of seconds.
