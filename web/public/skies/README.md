# Photographic skies

Shipped far-field plates, served as `/skies/<id>.jpg`.

| File | Backdrop id | Subject |
| --- | --- | --- |
| `earth.jpg` | `earth` | Earth from orbit |
| `meadow.jpg` | `meadow` | Sunny meadow |
| `tunnel.jpg` | `tunnel` | Dark tunnel |

These are original generated plates (not third-party stock). Operator overrides can live as RSS/HTTP/file sources; they do not replace these files.
